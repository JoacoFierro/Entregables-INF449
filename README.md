Repositorio de entregables para la asignatura **INF449 Fotografía Computacional - UTFSM**.

> 📌 Para usar esta plantilla, presiona el botón *__Use this template__* <img src="./img/template.png" width=80>.



## Descripción

Este repositorio organiza los trabajos del curso: tareas, exposición y proyecto final. La asignatura aborda fotografía digital, procesamiento de imágenes, problemas inversos, optimización y redes neuronales aplicadas a sistemas de formación y reconstrucción de imágenes.
